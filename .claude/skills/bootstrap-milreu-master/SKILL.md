# Skill — Bootstrap Milreu Master

## Procedimento

1. Confirmar que o utilizador já iniciou sessão.
2. Definir o e-mail em secret.
3. Usar terminal seguro.
4. Definir confirmação literal.
5. Executar bootstrap.
6. Consultar contagem de masters.
7. Testar proteção do último master.
