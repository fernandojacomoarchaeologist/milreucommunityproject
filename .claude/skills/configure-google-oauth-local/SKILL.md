# Skill — Configure Google Oauth Local

## Procedimento

1. Criar client web no Google.
2. Registar callback local do Supabase.
3. Configurar client ID e secret em variáveis locais.
4. Ativar o provider no config.toml.
5. Reiniciar Supabase local.
6. Executar OAuth checker.
7. Testar login e logout.
