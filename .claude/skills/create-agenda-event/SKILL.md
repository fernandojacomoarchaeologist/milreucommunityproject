# Skill — Create Agenda Event

## Procedimento

1. Definir título, tipo e horário.
2. Associar local ou período, quando aplicável.
3. Definir visibilidade.
4. Definir capacidade.
5. Rever inscrição e contacto.
6. Confirmar o evento.
7. Acompanhar respostas sem exposição pública dos nomes.
