# Skill — Create Exhibition Record

## Procedimento

1. Definir título e tipo.
2. Registar descrição de trabalho.
3. Registar resumo público quando aprovado.
4. Definir objetivos internos.
5. Manter a exposição separada dos seus períodos.
6. Não publicar automaticamente.
