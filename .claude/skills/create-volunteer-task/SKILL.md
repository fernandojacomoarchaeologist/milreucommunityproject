# Skill — Create Volunteer Task

## Procedimento

1. Definir objetivo e resultado esperado.
2. Escolher categoria e modalidade.
3. Definir datas, capacidade e modo de atribuição.
4. Indicar competências necessárias.
5. Guardar como rascunho.
6. Rever antes de publicar.
