# Skill — Process Withdrawal Request

## Procedimento

1. Validar código e e-mail.
2. Localizar contributo e utilizações.
3. Colocar pedido em análise.
4. Avaliar obrigações de retenção.
5. Aprovar ou fundamentar recusa.
6. Retirar usos públicos aplicáveis.
7. Concluir e comunicar.
