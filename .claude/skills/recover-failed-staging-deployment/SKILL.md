# Skill — Recover Failed Staging Deployment

## Procedimento

1. Suspender homologação.
2. Preservar logs.
3. Identificar migration ou configuração.
4. Criar correção versionada.
5. Restaurar backup se necessário.
6. Reexecutar dry-run.
7. Abrir nova execução.
