# Skill — Register Exhibition Venue

## Procedimento

1. Confirmar que o local é real e autorizado.
2. Registar os dados internos.
3. Separar os campos públicos.
4. Rever a informação de acessibilidade.
5. Manter em rascunho até validação.
6. Ativar a visibilidade pública somente com dados confirmados.
