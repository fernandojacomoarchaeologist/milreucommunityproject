# Skill — Respond Contribution Security Incident

## Procedimento

1. Suspender endpoint quando necessário.
2. Preservar logs.
3. Revogar URLs e tokens.
4. Isolar ficheiros.
5. Avaliar dados pessoais.
6. Informar responsáveis.
7. Corrigir e testar antes de reabrir.
