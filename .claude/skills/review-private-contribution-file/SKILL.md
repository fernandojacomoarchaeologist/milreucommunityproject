# Skill — Review Private Contribution File

## Procedimento

1. Não abrir diretamente sem procedimento seguro.
2. Confirmar MIME e tamanho.
3. Executar verificação técnica.
4. Rever conteúdo e direitos.
5. Aceitar, rejeitar ou eliminar.
6. Registar nota técnica.
