# Skill — Verify Private Storage Staging

## Procedimento

1. Submeter ficheiro de teste.
2. Confirmar bucket privado.
3. Confirmar URL assinada.
4. Testar utilizador não autorizado.
5. Testar expiração.
6. Registar evidência.
7. Eliminar ficheiro de teste conforme procedimento.
