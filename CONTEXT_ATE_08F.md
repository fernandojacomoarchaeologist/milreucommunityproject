# Contexto consolidado até ao Pacote 08F

O 08F fecha a fundação funcional da Área Colaborativa e cria o ciclo editorial das 31 memórias.

## Três níveis

```text
Rascunho e revisão
→ Supabase
```

```text
Snapshot aprovado
→ ficheiro editorial versionado
```

```text
Aplicação canónica
→ script local + validações + PR + merge
```

## Efeitos públicos

As páginas principais passam a aceitar efeitos por slots. O registo inicial está vazio, portanto nenhuma atualização editorial foi inventada.

## Formação

Cinco percursos apoiam revisão, direitos, tradução e acessibilidade. Aprovações especializadas exigem formação concluída.

## Limite

O pacote entrega a infraestrutura e o fluxo completo, mas não aprova sozinho nenhuma das 31 memórias.
