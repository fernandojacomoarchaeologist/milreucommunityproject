# Anexo III — Matriz de riscos

A matriz junta os 94 riscos mapeados nos capítulos 2 a 12. Cada risco tem a probabilidade e a gravidade atribuídas no seu capítulo, segundo a escala da secção 1.4. O nível resulta do produto das duas escalas (1 a 3 cada): Baixo até 2, Médio de 3 a 4, Alto de 6 a 9. As remissões para riscos de outra actividade (por exemplo, os riscos dos dispositivos no quiz) não se contam duas vezes. A matriz é uma apreciação qualitativa anterior aos pilotos e revê-se com os registos de ocorrências de cada teste (CRO §7.2). Este anexo é gerado pelo script do guia a partir das tabelas dos capítulos.
