# Disponibilidade

O membro pode registar:

- modos preferidos: remoto, presencial ou ambos;
- máximo indicativo de minutos semanais;
- fuso horário;
- notas;
- períodos recorrentes por dia da semana.

## Limites

- disponibilidade não cria obrigação;
- coordenação consulta apenas para organizar tarefas;
- não deve ser publicada;
- não deve ser usada para avaliar produtividade;
- exceções por data serão avaliadas num pacote posterior.
