# Arquitetura dos contributos

```text
Participante
├── identificação e contacto
├── contributo
├── consentimento
├── ficheiros
└── alvos indicados
```

```text
Moderação
├── triagem
├── atribuições
├── eventos
├── decisões
├── direitos
├── retirada
└── proposta de incorporação
```

A pessoa e o conteúdo são entidades separadas. Isso permite aplicar políticas mais restritivas aos dados pessoais.
