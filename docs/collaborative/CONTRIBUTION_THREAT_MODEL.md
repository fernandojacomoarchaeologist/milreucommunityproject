# Modelo de ameaças

## Riscos

- spam;
- upload malicioso;
- ficheiro excessivo;
- enumeração de contributos;
- exposição de PII;
- acesso indevido;
- falsificação de autoria;
- publicação acidental;
- retirada não processada.

## Controlos

- honeypot;
- rate limit;
- Turnstile opcional;
- bucket privado;
- URLs temporárias;
- tracking code de alta entropia;
- confirmação por e-mail correspondente;
- RLS;
- service role no servidor;
- consentimento versionado;
- decisão auditada;
- proposta em vez de publicação direta.

## Limites

O pacote não substitui antivírus, revisão humana, DPO ou avaliação jurídica.
