# Acessibilidade e privacidade

## Acessibilidade

Cada local possui:

- resumo público;
- notas internas;
- informação a validar no terreno.

A checklist inclui acessibilidade para rever:

- circulação;
- altura;
- contraste;
- leitura;
- assentos;
- condições sensoriais;
- orientação;
- acesso ao edifício.

## Privacidade

- participantes não são públicos;
- disponibilidade de voluntários continua interna;
- contactos internos não são exportados;
- notas logísticas permanecem restritas;
- apenas campos explicitamente públicos entram no snapshot.
