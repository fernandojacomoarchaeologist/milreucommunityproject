# Ciclo da exposição e itinerância

## Exposição

```text
planning → ready → active → completed → archived
                   ↘ paused
                   ↘ cancelled
```

## Período num local

```text
planned → confirmed → installed → open → closed
              ↘ cancelled
```

A publicação só é permitida para:

- confirmed;
- installed;
- open;
- closed.

O estado físico e o estado público permanecem separados.
