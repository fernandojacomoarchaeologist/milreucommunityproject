# Limite de incorporação

Um contributo aceite não altera dados canónicos.

O 08E cria uma proposta com:

- destino;
- identificador alvo;
- resumo;
- responsável;
- estado.

Destinos possíveis:

- Museu;
- Proteus;
- Portal;
- investigação;
- exposição;
- arquivo.

A aplicação editorial ocorrerá no 08F ou noutro pacote específico.
