# Mapa de campos

O modelo contém 22 campos ou grupos editáveis.

Campos textuais utilizam texto direto. Objetos e listas utilizam JSON válido. Não substituir o registo completo.

Caminhos seguem JSON Pointer, por exemplo:

```text
/title/pt-PT
/description/objective/pt-PT
/date/precision
/sources
/rights
```
