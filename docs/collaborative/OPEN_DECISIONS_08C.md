# Decisões em aberto após o 08C

- permitir mais de um período diário na interface definitiva;
- incluir exceções de disponibilidade por data;
- definir regras de cancelamento quando uma tarefa já começou;
- definir prazo máximo para validação de conclusões;
- definir política de reconhecimento de horas;
- decidir se haverá notificações internas;
- decidir se tarefas poderão ser associadas a exposições, eventos ou memórias;
- decidir se membros podem sugerir novas tarefas;
- decidir se haverá anexos no fluxo de conclusão.
