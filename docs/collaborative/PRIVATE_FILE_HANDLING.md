# Ficheiros privados

## Bucket

`community-contributions-private`

## Regras

- sem leitura pública;
- upload por URL assinada;
- download por URL assinada;
- máximo 25 MB;
- máximo cinco ficheiros;
- MIME permitido;
- caminho gerado pelo sistema;
- nome original preservado como metadado.

## Verificação

`scan-pending` não significa que existe antivírus integrado. Antes de abrir ou incorporar ficheiros, deve existir procedimento técnico de verificação.
