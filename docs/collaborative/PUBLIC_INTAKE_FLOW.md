# Fluxo público

```text
Formulário estático
→ Edge Function
→ validação
→ rate limit
→ consentimento
→ criação transacional
→ URL assinada
→ bucket privado
→ confirmação de upload
→ código de acompanhamento
```

O visitante não recebe acesso direto ao banco ou ao bucket.
