# Ciclo de vida das tarefas

## Tarefa

```text
draft → open → in-progress → completed → archived
               ↘ cancelled
```

## Participação

```text
invited → accepted → in-progress → submitted → completed
   ↘ declined       ↘ withdrawn      ↘ reopened

applied → accepted / declined / withdrawn
```

As mudanças são efetuadas por RPCs específicas e registadas na auditoria.
