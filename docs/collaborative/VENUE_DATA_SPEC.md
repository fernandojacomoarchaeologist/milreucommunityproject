# Especificação de locais

## Dados internos

- contacto;
- e-mail interno;
- notas;
- observações de acessibilidade;
- estado do relacionamento.

## Dados potencialmente públicos

- nome;
- tipo;
- localidade;
- município;
- morada;
- código postal;
- país;
- horário;
- descrição;
- URL;
- e-mail e telefone públicos;
- resumo de acessibilidade.

A publicação exige `public_visibility` e estado ativo. Um contacto interno nunca é usado como contacto público por inferência.
