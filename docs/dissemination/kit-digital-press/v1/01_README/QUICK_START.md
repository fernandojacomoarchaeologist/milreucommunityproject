# Quick Start

1. **Descrever a exposição** — usar `02_TEXTOS/DESCRICAO_50/100/250_PALAVRAS.txt` conforme o espaço.
2. **Imagens** — ver `04_IMAGENS/LEGENDAS_E_CREDITOS.csv`; usar só imagens com **redistribuição confirmada** e **sempre com a linha de crédito** indicada.
3. **Imprensa** — adaptar `03_PRESS/NOTA_DE_IMPRENSA_BASE.md` preenchendo os campos `[ ]` locais; anexar o `FACT_SHEET_1P`.
4. **Redes sociais** — usar as peças de `06_SOCIAL/` (institucional ou local).
5. **Site/partilha** — usar `07_WEB/` e o QR de `09_QR/`.
6. **Logótipos** — seguir `05_LOGOS/REGRAS_DE_USO.md`.
7. **Identidade / Marca do projecto** — descarregar o logótipo em `05_LOGOS/PROJECTO/` (PNG transparente; SVG/PDF **pendentes**) e seguir `REGRAS_DE_USO_DA_MARCA.md`. Design System público: `PUBLIC_DS_PAGE_PENDING_ITEM2`.
