## Ficheiros (300 dpi, RGB, com sangria 3 mm + marcas de corte)
- `flyer_a6_front_PRINT.pdf` / `flyer_a6_back_PRINT.pdf` — trim **105×148 mm** + sangria → **111×154 mm**.
- `marcador_59x214_front_PRINT.pdf` / `marcador_59x214_back_PRINT.pdf` — trim **59×214 mm** + sangria → **65×220 mm**.
- `_PREVIEW_print.png` + PNGs por face — provas.

## Fonte e método
- Arte: gerador `scratchpad/item5_build/build.py` → `../v6.4`. **Marcador = direcção aprovada (arte-final); Flyer = prova visual (ainda não final)** conforme `../v6.4/README.md`.
- Método: **escala uniforme** da arte aprovada (sem distorção); A5→A6 é escala √2; marcador 55×200→59×214 ≈ 1,07×. Sangria por replicação de bordo; marcas de corte nos cantos do trim.
- **QR real** para `https://projectomilreu.pt` (site verificado ao vivo — HTTP 200 — em 2026-10-01).
