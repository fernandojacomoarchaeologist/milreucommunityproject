# Critérios de aceitação

## Conteúdo

- fonte pt-PT;
- chaves estáveis;
- versão-fonte;
- tradução vinculada;
- deteção de stale.

## Workflow

- todos os estados;
- revisão humana;
- pedido de alterações;
- aprovação;
- publicação explícita;
- machine draft nunca público.

## Seletor

- idioma publicado funciona;
- idioma ausente apresenta mensagem;
- sem fallback silencioso;
- `lang` correto;
- foco preservado;
- sem URL falsa.

## Museu e oportunidades

- certeza, direitos e proveniência;
- dados operacionais preservados;
- MM202617 inalterada.

## Regressão

- Playwright verde;
- 09B e 09C preservados;
- snapshots não atualizados automaticamente;
- produção bloqueada.
