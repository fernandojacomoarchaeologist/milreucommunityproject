# Matriz de eventos

Vinte eventos cobrem:

- acesso;
- convites;
- tarefas;
- contributos;
- Museu;
- formação;
- agenda;
- exposições;
- retirada;
- homologação.

Cada evento define categoria, prioridade, obrigatoriedade no centro interno, possibilidade de e-mail, padrão de e-mail, retenção e rota.
