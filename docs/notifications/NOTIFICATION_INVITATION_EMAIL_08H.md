# E-mail de convite

A pré-autorização não envia mensagem.

O gestor deve:

1. rever o e-mail;
2. confirmar perfil;
3. confirmar estado pendente;
4. selecionar “Enfileirar e-mail”;
5. verificar outbox;
6. acompanhar entrega.

A mensagem não contém password nem token de acesso.
