# Decisão: sem chat interno

O 08H não cria chat.

Razões:

- moderação;
- retenção;
- privacidade;
- notificações duplicadas;
- dispersão documental;
- risco de decisões fora dos fluxos auditáveis.

Comentários permanecem ligados a tarefas, contributos e revisão editorial.
