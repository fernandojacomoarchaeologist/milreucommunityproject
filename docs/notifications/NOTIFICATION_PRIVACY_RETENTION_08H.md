# Privacidade e retenção

- não incluir informação sensível desnecessária;
- não incluir testemunhos, documentos ou decisões completas no e-mail;
- utilizar link para a Área Colaborativa;
- mascarar endereço no painel;
- não expor payload;
- apagar notificações após a retenção do evento;
- apagar outbox entregue ou cancelada após 180 dias;
- preservar delivery suficiente para auditoria operacional;
- pedidos de retirada mantêm retenção superior.
