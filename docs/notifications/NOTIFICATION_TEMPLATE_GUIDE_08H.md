# Guia de templates

Fonte:

- assunto;
- título;
- corpo em texto simples.

O worker cria HTML escapado. HTML arbitrário não é permitido.

Tokens:

```text
display_name
project_name
title
status
reference
action_url
due_at
starts_at
role
reason
environment
```

Templates aprovados são imutáveis. Uma correção cria versão nova.
