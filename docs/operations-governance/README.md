# Operação pública, governação, monitorização e sustentabilidade (08M)

© 2026 Fernando Rodrigues de Jácomo. Produzido no âmbito do Projeto Comunitário de Milreu. Consultar RIGHTS.md.

Documenta a operação real (ciclos, responsabilidades), suporte e moderação, revisão periódica de conteúdo, decisões de governação, indicadores (operacional/participação/impacto) e transparência pública por snapshot, continuidade/handover e desativação segura. Nenhum ciclo operacional real, responsável ou indicador é semeado; a transparência pública está desativada por omissão; o público lê apenas snapshots aprovados; produção permanece bloqueada.
