# Backup e restauração

O registo de um plano não é evidência.

Uma verificação deve indicar:

- data observada;
- estado;
- evidência privada;
- se a restauração foi testada;
- RPO;
- RTO;
- notas;
- responsável.

Nunca incluir passwords, dumps ou tokens nos registos.
