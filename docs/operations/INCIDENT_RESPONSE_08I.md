# Resposta a incidentes

## SEV-1

Impacto crítico ou risco elevado para dados, direitos ou operação.

## SEV-2

Impacto elevado e necessidade de resposta coordenada.

## SEV-3

Impacto limitado ou restrito a staging/grupo.

## SEV-4

Anomalia menor sem impacto significativo.

Fluxo:

1. abrir;
2. reconhecer;
3. investigar;
4. mitigar;
5. monitorizar;
6. resolver;
7. fechar;
8. realizar postmortem quando aplicável.
