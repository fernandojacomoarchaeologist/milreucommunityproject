# Checks operacionais

Vinte checks cobrem:

- banco;
- autenticação;
- auditoria;
- storage;
- notificações;
- backups;
- retenção;
- incidentes;
- publicação;
- staging;
- produção;
- secrets;
- continuidade.

Checks bloqueantes falhados tornam a execução bloqueada.
