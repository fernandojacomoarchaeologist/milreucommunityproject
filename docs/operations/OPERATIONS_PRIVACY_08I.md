# Privacidade operacional

- redigir e-mails;
- não guardar tokens;
- não guardar secrets;
- não exportar snapshots completos;
- minimizar descrições de incidente;
- usar evidências privadas;
- evitar nomes pessoais quando uma função basta;
- não publicar summaries internos automaticamente.
