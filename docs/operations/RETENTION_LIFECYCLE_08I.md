# Ciclo de retenção

```text
preview
→ revisão
→ legal holds
→ aprovação
→ workflow
→ aplicação
→ auditoria
```

A aplicação só é permitida quando:

- a política está ativa;
- a ação é suportada;
- o hash dos candidatos não mudou;
- os legal holds não mudaram;
- a execução foi aprovada;
- o worker possui service role;
- os literais foram confirmados.
