# Manifesto

- versão: `0.33.0`
- base obrigatória: `09C (#39) → 09D (#40) → 09C.1`
- objetivo: fecho funcional, não expansão de domínio
- novos módulos: 0
- novas permissões: 0
- novas migrations: 0
- exceções: apenas por bloqueio técnico comprovado e documentado antes da implementação
- idiomas de implementação: interface integrada ao 09D; conteúdo operacional inicialmente em `pt-PT`
- traduções EN/ES/FR: `missing`, `draft` ou `in-review`; nunca publicadas automaticamente
- dados fictícios visíveis: proibidos
- dados pessoais em screenshots, logs e artefactos: proibidos
- produção: bloqueada
- merge automático: proibido

Se o 09D ainda não estiver integrado e verde no `main`, o pacote deve parar no preflight e reportar o bloqueio.
