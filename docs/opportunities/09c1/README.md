# Pacote 09C.1 — Fecho funcional e homologação das oportunidades

**Versão:** `0.33.0`  
**Base obrigatória:** 09C e 09D integrados no `main`, nesta ordem.

## Objetivo

Fechar a diferença entre a fundação técnica do 09C e a jornada comprovadamente utilizável, preservando integralmente o modelo multilíngue do 09D.

```text
master cria rascunho → pré-visualiza → publica
→ visitante consulta → autentica → completa perfil mínimo
→ candidata-se → master decide → participante consulta o resultado
```

## Resultado esperado

- interfaces funcionais para candidato e master;
- descoberta pública e colaborativa das oportunidades;
- perfil mínimo com retorno seguro à oportunidade;
- estados e ações completos, sem workflow complexo;
- privacidade comprovada entre perfis;
- menores bloqueados até política aprovada;
- Formação sem percursos, notas ou progressos fictícios;
- compatibilidade com o 09D, sem traduções automáticas publicadas;
- E2E real, evidências atuais e relatório sem exageros.

## Fora de escopo

- novos idiomas ou traduções completas;
- lista de espera automática;
- OAuth social ou publicação automática;
- pagamentos, contratação ou e-mail transacional;
- política de menores;
- Proteus, SEO completo ou produção.
