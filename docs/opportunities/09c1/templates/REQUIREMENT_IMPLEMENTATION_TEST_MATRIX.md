# Matriz requisito × implementação × teste

| ID | Requisito | Estado anterior | Implementação/ficheiro | Teste | Evidência | Ambiente | Estado final |
|---|---|---|---|---|---|---|---|

Estados permitidos: `implemented`, `partial`, `not-implemented`, `blocked`, `not-applicable`.

Não classificar como `implemented` apenas por existir contrato, RPC, componente sem ligação, mock ou teste unitário.
