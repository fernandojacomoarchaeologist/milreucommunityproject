# Manifesto do Pacote 10A

Contém 24 ficheiros: 14 documentos operacionais, 6 contratos JSON, 2 templates, o índice JSON e este manifesto.

Base: 09F integrado e comprovado no preflight · alvo: `v0.36.0` / `currentPackage 10A`.

Escopo positivo: manifesto Proteus, públicos, classes epistémicas, proveniência, direitos, acesso, uso por IA, confiança, citações, fontes restritas, recursos institucionais externos, governação, privacidade, segurança e contrato futuro MCP somente de leitura.

Escopo negativo: UI completa, catálogo produtivo, documentos integrais, extração/OCR, embeddings, RAG, chat, API pública, servidor MCP, OAuth MCP, ingestão real, migrações de produção e publicação automática.

Qualquer divergência entre este manifesto, o ZIP e `PACKAGE_INDEX.json` interrompe o preflight.
