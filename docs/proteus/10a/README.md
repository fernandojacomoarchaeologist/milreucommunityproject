# Pacote 10A — Política pública, direitos, confiança e contrato futuro do MCP

Versão alvo: `0.36.0`. Base obrigatória: 09F integrado no `main`, com SHA, versão, `currentPackage` e CI confirmados no preflight. Não inferir o SHA do merge.

Este pacote inaugura a Série 10 — Experiência Proteus. Define a política pública e editorial, as classes de conhecimento, o modelo de direitos, o contrato de confiança das respostas e o contrato futuro do MCP. Não cria ainda biblioteca, chat, API, servidor MCP, embeddings ou ingestão de documentos.

Proteus é a infraestrutura pública de conhecimento sobre Milreu: humana, citável, indexável e preparada para agentes. Não é uma Wikipédia, um repositório indiscriminado de PDFs nem apenas um chatbot.
