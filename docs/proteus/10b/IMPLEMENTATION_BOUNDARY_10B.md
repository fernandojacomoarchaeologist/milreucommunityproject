# Fronteira de implementação

## Deve existir após 10B

- modelo bibliográfico e de autores validado;
- direitos separados de acesso;
- rascunho DOI sem publicação automática;
- páginas públicas iniciais com estado vazio honesto;
- fluxo editorial usando autorização existente;
- entidades publicadas indexáveis e rascunhos privados;
- auditoria e testes.

## Não deve existir

- obra, autor ou licença fabricados;
- PDF, OCR, texto extraído, embedding ou resumo gerado;
- claim, interpretação ou grafo de conhecimento;
- chat, API pública ou MCP;
- novo papel/permissão;
- mais de uma migration;
- dependência de rede real no CI;
- produção ativada.

## Continuidade

10C adicionará afirmações, fontes localizadas, divergências e modelo de conhecimento. 10D amadurecerá biblioteca e API pública. Ingestão documental continua no 10E.
