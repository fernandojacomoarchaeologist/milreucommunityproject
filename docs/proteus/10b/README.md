# Pacote 10B — Catálogo bibliográfico, autores, direitos e páginas públicas iniciais

Versão alvo: `0.37.0`. Base obrigatória: `main@0430da5`, `v0.36.0`, `currentPackage 10A`, CI verde e árvore limpa. Se o repositório remoto divergir, interromper e relatar; não rebasear silenciosamente.

O 10B cria a primeira camada funcional da Biblioteca Proteus: catálogo de obras, autores e identificadores; estados de acesso e direitos; importação assistida por DOI; páginas públicas iniciais; pesquisa e filtros básicos; revisão humana antes de publicar.

O pacote não inclui PDFs, OCR, texto integral, resumos automáticos, afirmações epistémicas, embeddings, RAG, chat, API pública ou MCP.
