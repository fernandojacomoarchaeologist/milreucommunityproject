# Evidência localizada e proveniência

Cada evidência aponta para uma obra ou recurso existente e inclui um localizador verificável: página, intervalo de páginas, secção, figura, tabela, fragmento temporal ou URL com data de consulta. Citações textuais são opcionais e dependem de direitos; localização e paráfrase não autorizam redistribuição do original.

Localizadores devem preservar edição/versão, idioma, data de acesso e método de obtenção. Uma URL dinâmica nunca é prova permanente sem captura temporal autorizada ou data de verificação.

Proveniência distingue: fonte original, registo catalográfico, derivado editorial, responsável pela proposta, revisor, datas, ferramenta utilizada e transformações. Conteúdo sugerido por IA deve ser marcado como proposta e nunca publicado sem revisão humana.

Ausência de página num recurso paginado é erro bloqueante; fontes não paginadas devem usar outro tipo de localizador explícito.
