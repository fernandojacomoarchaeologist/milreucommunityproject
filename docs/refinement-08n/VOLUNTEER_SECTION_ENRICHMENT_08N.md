# Enriquecimento das secções do voluntário

## Estrutura comum

Sempre que tecnicamente e editorialmente viável, cada secção deve apresentar quatro blocos:

### 1. Objetivo desta secção
Texto curto que explica a finalidade.

### 2. Ações esperadas
Lista curta de ações concretas que o voluntário pode ou deve realizar.

### 3. Pequeno guia
Passos curtos ou orientação de uso inicial.

### 4. Detalhes
Conteúdo já existente, reorganizado ou mantido.

## Regras editoriais

- linguagem em `pt-PT`;
- frases curtas;
- evitar tom burocrático;
- evitar duplicar instruções noutras secções;
- não esconder dados relevantes dentro do guia;
- não transformar cada secção numa página de documentação longa.

## Aplicação mínima

O Claude deve aplicar a estrutura pelo menos a:

- O meu perfil
- Notificações
- Disponibilidade
- As minhas tarefas
- Contributos
- Agenda e exposições
- Biblioteca
- Formação
- Revisão do Museu

## Início

A home não precisa reproduzir os quatro blocos completos. Pode usar:

- resumo;
- ações pendentes;
- atalhos úteis;
- próximos passos.

## Formação

Como ficará apenas um percurso visível, a secção pode incluir:

- objetivo da formação;
- porque é importante;
- como continuar;
- estado atual do percurso.

## Revisão do Museu

Se o voluntário não tiver pré-requisitos ou permissões suficientes, a secção deve explicitar isso com clareza, em vez de parecer vazia ou quebrada.
