# Licença e privacidade de fontes

Para cada fonte, guardar nome, versão, autor/origem, URL de referência, licença, ficheiro de licença, formatos e subconjuntos. Não copiar ficheiros cuja licença seja desconhecida.

Preferir ativos self-hosted versionados. Se houver chamada externa, medir impacto e documentar fornecedor, dados transmitidos, base institucional e alternativa; não mantê-la por conveniência. Nenhum token ou credencial deve integrar CSS, HTML, logs ou pacote.

O relatório deve separar: licença confirmada; licença pendente; fonte declarada mas ausente; fonte presente mas não utilizada.
