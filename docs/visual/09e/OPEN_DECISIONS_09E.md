# Decisões abertas

Não bloquear o inventário ou melhorias seguras, mas levar para decisão humana:

- família tipográfica final caso configuração, intenção visual e licenças divirjam;
- ativos com autoria/direitos desconhecidos;
- crops que exijam julgamento histórico/editorial;
- qualidade/peso quando não houver variante claramente superior;
- chamada externa inevitável para fontes ou media;
- intervenção digital não documentada;
- exceção a budget com benefício editorial comprovado.

Fernando Jácomo permanece responsável pela aprovação editorial final. O Claude não deve resolver silenciosamente estas decisões.
