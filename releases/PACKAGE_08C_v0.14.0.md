# Release — Pacote 08C v0.14.0

Implementa o fluxo de voluntariado e tarefas da Área Colaborativa: disponibilidade, oportunidades, candidaturas, convites, progresso, registo de tempo, validação e gestão operacional.

O pacote não implementa notificações, calendário de exposições, contributos comunitários ou reconhecimento automático.
